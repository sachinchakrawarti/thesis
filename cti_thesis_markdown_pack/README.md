# CTI Thesis and Implementation Workspace

**Working thesis title:** Real-Time Cyber Threat Classification and
Emerging Threat Detection Using Machine Learning and Temporal Topic
Modeling

This workspace separates the project into: 1. Implementation
documentation 2. Base-paper analysis 3. Related/review-paper notes 4.
Thesis chapters 5. Experimental evidence and references

## Important research integrity note

The project uses a synthetic CTI report dataset. Treat results as
prototype results on synthetic data, not proof of real-world
threat-detection performance. Never enter metrics into the thesis until
they have been generated by the current notebook and checked.

## Recommended order

1.  Read `implementation/01_project_setup.md`.
2.  Run the notebook from the first cell and record errors.
3.  Confirm dataset columns and date coverage.
4.  Train and evaluate classification baselines.
5.  Run topic modeling and inspect weekly trends.
6.  Record only verified results in `results/`.
7.  Complete thesis chapters using the evidence produced.
8.  Verify every reference in `references/References.md`.

## Current dataset

Expected CSV filename: `synthetic_cti_reports.csv`. Update the path in
your notebook if needed. Expected useful fields include `title`, `text`,
`category`, and `date`; confirm the actual schema with
`df.columns.tolist()`.

## What this pack does not claim

It does not claim the model is deployed in a live security operations
center, does not establish real-world accuracy from synthetic records,
and does not claim that a topic spike proves a real attack campaign.
