# CTI मॉडल आर्टिफैक्ट्स — हिंदी दस्तावेज़

## 1. परिचय

यह डायरेक्टरी हमारे शोध प्रोजेक्ट के प्रशिक्षित मशीन लर्निंग मॉडल और संबंधित फाइलों को संग्रहीत करने के लिए बनाई गई है।

**शोध का शीर्षक:**

Machine Learning और Temporal Topic Modeling का उपयोग करके Real-Time Cyber Threat Classification और Emerging Threat Detection.

इस प्रोजेक्ट का उद्देश्य Cyber Threat Intelligence (CTI) रिपोर्ट का विश्लेषण करना, खतरे की श्रेणी निर्धारित करना तथा समय के साथ बदलते खतरे के पैटर्न का अध्ययन करना है।

## 2. प्रशिक्षित मॉडल

**फाइल का नाम:** `cti_text_classifier.joblib`

**फाइल फॉर्मेट:** Joblib

यह फाइल प्रशिक्षित मशीन लर्निंग पाइपलाइन को संग्रहीत करती है।

इसमें दो मुख्य घटक शामिल हैं:

1. **TF-IDF Vectorizer:** रिपोर्ट के टेक्स्ट को संख्यात्मक फीचर्स में बदलता है।
2. **Trained Classifier:** टेक्स्ट फीचर्स के आधार पर रिपोर्ट की संभावित खतरा श्रेणी का अनुमान लगाता है।

मॉडल का चयन परीक्षण डेटासेट पर प्राप्त Weighted F1-score के आधार पर किया जाता है।

## 3. मॉडल कैसे प्रशिक्षित होता है?

मॉडल को निम्नलिखित Jupyter Notebook में प्रशिक्षित किया जाता है:

`notebooks/cti_threat_analysis.ipynb`

प्रशिक्षण की प्रक्रिया:

1. CTI रिपोर्ट डेटासेट लोड करना।
2. टेक्स्ट और लेबल को साफ करना।
3. TF-IDF के माध्यम से टेक्स्ट फीचर्स तैयार करना।
4. Logistic Regression, Multinomial Naive Bayes और Linear SVM को प्रशिक्षित करना।
5. Accuracy, Precision, Recall और F1-score से मूल्यांकन करना।
6. सर्वश्रेष्ठ प्रदर्शन करने वाली बेसलाइन पाइपलाइन का चयन करना।
7. प्रशिक्षित मॉडल को Joblib फाइल में सेव करना।

## 4. सेव किए गए मॉडल का उपयोग

मॉडल को दोबारा प्रशिक्षित किए बिना लोड करने के लिए निम्नलिखित Python कोड का उपयोग किया जा सकता है:

```python
import joblib

model = joblib.load(
    "artifacts/cti_text_classifier.joblib"
)

report = """
एक संदिग्ध ईमेल कर्मचारियों के लॉगिन क्रेडेंशियल
चुराने का प्रयास करता है।
"""

prediction = model.predict([report])[0]

print("अनुमानित खतरे की श्रेणी:", prediction)
```

यह कोड प्रोजेक्ट की मुख्य डायरेक्टरी से चलाएँ, या मॉडल फाइल का सही पाथ दें।
